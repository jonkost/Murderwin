# Portraits

Drop one picture per character in this folder and the phones show it on the
character card. Square works best (the phone crops to a circle), PNG or JPG,
about 600 by 600 pixels. Name each file exactly like this:

| File | Character |
|---|---|
| white.png | Preston White, the Reporter |
| arms.png | Roger Arms, the Sergeant Major |
| rye.png | Dorothy Rye, the Baker |
| ledger.png | Prudence Ledger, the Banker |
| devine.png | Iris DeVine, the Florist |
| barnes.png | Hayward Barnes, the Farmer |
| fume.png | Ignatius Fume, the Scientist |
| mourningstone.png | Madame Opal Mourningstone, the Medium |
| steeps.png | Jasper Steeps, the Barista |
| vayne.png | Constance Vayne, the Influencer |
| shushwell.png | Dr. Paige Shushwell, the Librarian |
| leech.png | Dr. Bartholomew Leech, the Doctor |
| prof-jonathan.png | Prof. Jonathan Kostington |
| prof-susan.png | Prof. Susan Kostington |

A `.jpg` works too: name it `white.jpg` and so on. A character with no file
shows its initials. Run `npm run deploy:site` afterwards to put them online.

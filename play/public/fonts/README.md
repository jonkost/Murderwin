# Fonts

`AbrilFatface-Regular.ttf` is the big-words face of the look (handoff 11 Nov
2026, "The look"): the same face as the reveal name cards. It is kept here so
the site carries it itself and nothing is fetched on the night.

(www.type-together.com), with Reserved Font Names "Abril" and "Abril
Fatface". Licensed under the SIL Open Font License, Version 1.1
(http://scripts.sil.org/OFL), which allows it to be bundled with a site.

The game finds it by this exact file name (`play/src/look/look.css`).

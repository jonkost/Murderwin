## What Claude Code needs to do

1. **Find the clips.** They are not in the repo. Ask Jon once where they are
   and how they are named. Claude chat did not see them, so it does not know
   whether there is one clip per character or one per character per role.
2. **Keep the sound, drop the picture.** Simplest build that fits the house
   rules: for each clip, make an MP4 (H.264, AAC) whose picture is the still
   image for its whole length and whose sound is the clip's sound, untouched.
   `ffmpeg -loop 1 -i <image> -i <clip> -map 0:v -map 1:a -c:v libx264
   -tune stillimage -pix_fmt yuv420p -c:a aac -shortest <out>.mp4` does it.
   If the clips' sound is already AAC, `-c:a copy` keeps it bit for bit.
   The other option is to play the sound file and show the image as a card;
   choose whichever is the simpler fit for `finale.js`.
3. **Fit it into the closing bulletin.** `seed/woof-news.json` `closing.parts`
   cuts a name card in after `woof-close-field-murderer` (card `murderer`) and
   after `woof-close-field-victim` (card `ghost`); `play/src/lib/finale.js`
   and `play/src/lib/rooms.js` time them by `holdMs`. The new image and sound
   belong at those two cards. Set the hold from each clip's real length.
   The reveal order stays Murderer, Motive, Victim.
4. **Fallback.** A missing file must never stop the night: the existing name
   card shows instead, as the words already do for a missing bulletin video.
5. **House rules.** Add the files to `docs/media.md` and `npm run media`,
   cover any new host step in `docs/on-the-night.md`, add a board card through
   an ADDITIONS migration, add a `docs/sessions.md` entry, and write "Applied
   <date>" at the top of this file. The last new feature was due Wednesday 11
   November, so ask Jon whether this goes in before the party or is cut.

# The motive cards

Nineteen pictures, one for each motive, named by the motive's number in
`seed/motives.json`: `1.png` to `19.png`, saved straight in this folder
(`play/public/motives/`). "The last of the pie" shows pizza.

They show on the Parlour TV in two places: beside each motive Sir Irwin
names in his Act 5 countdown, and on the motive's card when it is revealed
in Act 7. A motive whose picture is not in yet shows its rhyme only, so the
game works with none, some or all of them. Run `npm run deploy:site` after
adding pictures to put them online.
